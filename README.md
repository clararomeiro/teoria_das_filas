# Calculadora de Teoria das Filas
Site feito para calcular as métricas de teoria das filas.

## Setup
Para esse setup é necessário ter o **npm** instalado e uma versão superior a 20 do node.

### Backend:
Para iniciar o backend entre na pasta `backend` pelo terminal e rode um npm install, ele instalará todas as dependências necessárias.
 
 `npm install`

 Após isso, basta rodar o comando abaixo e o backend iniciará:

 `npm run start`

 ### Frontend

 Para iniciar o frontend, é necessário navegar até a pasta `frontend/fila-simulator` e rodar também um `npm install`

 Após isso basta rodar o `npm run dev` e o frontend iniciará.

 #### Para acessar o site, basta entrar ir para localhost:5173
